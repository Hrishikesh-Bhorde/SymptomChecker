# Symptom Checker
 AI powered application for analyzing symptoms and getting possible cure. Developed using Streamlit, Python, Groq.

## For running in local
### requirements.txt
You'll need following libraries
1. streamlit
2. groq
3. openai
4. chromadb
5. dotenv

### .env
Create a .env file and add your API key
GROQ_API_KEY=YOUR_KEY

### To start application
CMD: streamlit run Symptom_checker.py
